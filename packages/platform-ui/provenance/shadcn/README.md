# shadcn/ui React Aria source basis

These files are immutable provenance snapshots from shadcn/ui revision
`3ba91b1cc83e1bbe4ab35a422ff2a694849c5048`:

- `button.tsx`
- `dialog.tsx`
- `field.tsx`
- `input.tsx`

They are not imported by the runtime build. The production components in `../../src/components` are local adaptations of these sources using the pinned
`react-aria-components` primitives, CoffeeOrderPlatform tokens, the package
`cn` helper, native input/button refs, the accepted close policy, and the
transport-neutral package boundary. Attribution and the MIT notice are in
`../../THIRD_PARTY_NOTICES.md`.
