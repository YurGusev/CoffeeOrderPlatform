# Неизвестный маршрут

Адрес, который не совпал ни с одним маршрутом, показывает «Маршрут не найден»
и ссылку «К клиентам». Страница собрана в `apps/web/src/browser/routes/NotFoundPage.tsx`.
Компонент подключён как `path="*"` в `App.tsx`.

## Sub-features

- `not-found-page` не покрыто. Видны eyebrow «404», заголовок «Маршрут не найден» и ссылка «К клиентам».

## How to get to it (user POV)

- После сессии открыть путь вне `/`, `/app` и вложенных маршрутов `App`.
- Обновить такой адрес. Для Vite fallback на `index.html` отдаёт оболочку SPA, а заголовок 404 рисует уже React.

## Driving it with verify-web

Preconditions:

- `SessionBoundary` оборачивает и страницу 404. Без сессии React до `NotFoundPage` не доходит.
- Сценарий `not-found-page` остаётся `not-covered`.

- **Не принимать закрытый неизвестный путь за 404.** `session-unknown-closed` открывает `/no-such-page` и требует, чтобы текста «Маршрут не найден» не было. Это проверка входа, не эта фича.
- **Страница 404, когда сессия уже есть.** Открыть `/no-such-page` после входа. Виден заголовок «Маршрут не найден» и ссылка «К клиентам» на `/app/customers`.

## Gotchas

- Путь `/app/orders/not-an-order` попадает в маршрут карточки, а не в `*`.
- Путь `/app/catalog` и остальные известные маршруты тоже не являются 404.
- Nginx-редирект `/` описан в `docs/launch/30_FRONTEND_OPERATOR_RUNBOOK.md`. Локальный Vite этот редирект сам не делает. Редирект в React стоит отдельно и тоже ждёт сессию.
