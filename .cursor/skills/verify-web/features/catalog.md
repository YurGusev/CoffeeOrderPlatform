# Каталог

Страница `/app/catalog` ищет товар в контексте черновика. Без корректного
`orderRef` она показывает «Не выбран заказ». С корректным `orderRef`
заголовок «Поиск товаров». Страница собрана в `apps/web/src/browser/routes/CatalogPage.tsx`.

## Sub-features

- `catalog-without-order` не покрыто. Путь без годного `orderRef` показывает «Не выбран заказ».
- `catalog-search` не покрыто. Поле «Название товара», список «Доступность» и кнопка «Найти».
- `catalog-add` не покрыто. У товара есть «Количество», при наличии вариантов «Помол», и кнопка «Добавить».

## How to get to it (user POV)

- После сессии открыть `/app/catalog`.
- Нажать «Каталог» в навигации.
- С карточки заказа перейти по «Открыть каталог». Адрес тогда содержит `orderRef`.

## Driving it with verify-web

Preconditions:

- Нужен `GET /auth/session` со статусом 200. Этот рычаг его не получает.
- Сценарии `catalog-without-order`, `catalog-search` и `catalog-add` остаются `not-covered`.

- **Не продолжать на экране входа.** `node .cursor/skills/verify-web/run.mjs` не считает закрытый `/app/catalog` проверкой каталога.
- **Без заказа, когда сессия уже есть.** Открыть `/app/catalog`. Виден текст «Не выбран заказ» и ссылка «поиск клиентов». Заголовка «Поиск товаров» нет.
- **Поиск и добавление, когда сессия и заказ уже есть.** Открыть `/app/catalog?orderRef=<ord_...>`. Виден заголовок «Поиск товаров». Короткий запрос показывает «Слишком короткий запрос». Пустая выдача показывает «Товары не найдены». Кнопка «Добавить» после успеха показывает «Товар добавлен».

## Gotchas

- Годный `orderRef` в коде совпадает с `^ord_[0-9A-HJKMNP-TV-Z]{26}$`.
- «Цена устарела», «Помол недоступен» и диалог «Заказ изменился на сервере» есть в странице и этим рычагом не покрыты.
- Фильтр доступности имеет значения «Все», «Доступные», «Недоступные», «Остановленные».
- Ссылка «К заказу» ведёт на `/app/orders/<orderRef>`.
