# Клиенты

Страница `/app/customers` ищет клиента и создаёт нового. Заголовок страницы
«Клиенты». Страница собрана в `apps/web/src/browser/routes/CustomersPage.tsx`.

## Sub-features

- `customers-search` не покрыто. Пустой поиск показывает «Начните поиск клиента». Запрос короче двух символов показывает «Слишком короткий запрос». Пустая выдача показывает «Клиенты не найдены».
- `customers-create` не покрыто. Кнопка «Новый клиент» открывает диалог «Новый клиент». Кнопка «Создать и выбрать» отправляет создание.

## How to get to it (user POV)

- После сессии открыть `/app/customers`.
- Нажать «Клиенты» в основной или мобильной навигации.
- После сессии открыть `/` или `/app`. Оба маршрута заменяются на `/app/customers`.
- Со страницы 404 перейти по ссылке «К клиентам».

## Driving it with verify-web

Preconditions:

- Нужен `GET /auth/session` со статусом 200. Этот рычаг поднимает только Vite и такого ответа не получает.
- Пока предусловие не выполнено, сценарии остаются `not-covered`.

- **Не продолжать на экране входа.** Запуск `node .cursor/skills/verify-web/run.mjs` пишет `customers-search` и `customers-create` как `not-covered`. Текст «Требуется вход» эти id не закрывает.
- **Поиск, когда сессия уже есть.** Открыть `/app/customers`. Видны поле «Имя, телефон или email», кнопка «Найти» и текст «Начните поиск клиента». Ввести один символ. Виден текст «Слишком короткий запрос».
- **Создание, когда сессия уже есть.** Нажать «Новый клиент». Виден диалог «Новый клиент» с полями «Имя», «Телефон», «Email» и кнопкой «Создать и выбрать».

## Gotchas

- Поиск короче двух символов не вызывает API. Это видно по тексту предупреждения, а не по отсутствию запроса в отладчике.
- Успешное создание уходит на `/app/orders/new?customerRef=...`. Без Customer owner кнопка не доказывает сохранённую строку.
- Ответ 403 показывает «Недостаточно прав». Этот рычаг его не вызывает.
- Кнопка «Выбрать» и «Следующая страница» появляются только на выдаче поиска.
