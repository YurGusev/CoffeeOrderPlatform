# Sol и Terra для CoffeeOrderPlatform

Локальная адаптация [donvito/codex-astra-luna-orchestrator](https://github.com/donvito/codex-astra-luna-orchestrator).

> Codex-режим отдельный и не является текущим DSH-процессом. Для DSH использовать нативный `subagent` и правила `AGENTS.md`.

| Режим | Root | Исполнительские роли | Reviewer | Лимит субагентов |
|---|---|---|---|---|
| Обычный | GPT-6.1 Sol, reasoning из настроек пользователя | GPT-6.1 Terra: explorer/researcher low, worker/tester xhigh | GPT-6.1 Sol high | 4 |
| Большой | GPT-6.1 Sol medium | GPT-6.1 Terra: explorer/researcher low, worker/tester xhigh | GPT-6.1 Sol high | 8 |

Лимит исключает корневого агента; это потолок, а не обязательное число.
Начинать с одного исполнителя для содержательной подзадачи; добавлять остальных только
для независимой работы. Для простого изменения субагенты не нужны.

Из корня проекта:

```bash
codex # Root GPT-6.1 Sol из конфигурации проекта
bash .codex/large.sh # Большой
```

Большой запуск принимает аргументы Codex, например:
`bash .codex/large.sh exec 'Описание задачи'`.
Режимы проверены на Codex CLI 0.153.2 до изменения моделей. Большой запуск задаёт
reasoning root и лимит субагентов через CLI overrides. Глобальные профили для этих
режимов не создаются.
[Документация профилей](https://developers.openai.com/codex/config-advanced/#profiles).

Проект задаёт GPT-6.1 Sol как модель root по умолчанию; reasoning берётся из выбора
пользователя или его настроек. В Desktop и параметрами запуска модель можно
переопределить; тогда фактическая модель root может отличаться от схемы ниже,
а reviewer останется GPT-6.1 Sol high. Для воспроизводимого большого режима использовать
команду выше в терминале. Она не переключает открытые задачи Desktop.

Codex-режим описан в этом файле; после изменения конфигурации агентов использовать
новую сессию. Глобальные настройки не изменяются.
Роли explorer и researcher закреплены на GPT-6.1 Terra low, worker и tester —
на GPT-6.1 Terra xhigh; reviewer закреплён на GPT-6.1 Sol high в обоих режимах.

## Передача работы и возврат замечаний

```text
                  GPT-6.1 Sol
               root / orchestrator
                       |
       +---------------+---------------+
       |               |               |
    explorer         worker        researcher
      Terra           Terra           Terra
       +---------------+---------------+
                       |
                     tester
                      Terra
                       |
                    reviewer
                      Sol
                       |
                  GPT-6.1 Sol
               integrate + verify
```

Root — основной агент задачи; reviewer — отдельный субагент Sol.
Reviewer сообщает root замечания, рекомендуемую роль и критерии приёмки.
Root организует исправления, tester проверяет их, reviewer повторяет ревью.
Подробные правила — в разделе «Передача работы и возврат замечаний» этого файла.
Порядок закреплён в developer_instructions проектного config.toml и навыке.
Стрелки означают передачу результатов через root; дети не запускают детей.
Это порядок работы агентов по инструкциям, а не автоматический CI workflow.

*Merge PR и закрытие issue выполняет root после обязательных проверок и при
явном разрешении пользователя.

## Экономия Sol

Root выполняет краткую первичную проверку и передаёт подробный поиск explorer,
реализацию worker, проверки tester. Внешние источники изучает researcher.
Sol принимает архитектурные решения и результат независимого reviewer;
не повторяет весь поиск, тестовый прогон и ревью без новых оснований.
Точные границы — в `config.toml` и разделе «Экономия Sol» этого файла.
Настройка задаёт поведение, а не жёсткий бюджет токенов и не автоматический
маршрутизатор. Для применения в Desktop открыть новую задачу с GPT-6.1 Sol.
